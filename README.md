Entry for [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) on [make.fun](https://make.fun).

`main.py` writes one line — the label a year-3000 museum puts beside a group chat — to `/output/entry.txt`. Standard library only, deterministic.

> Group Chat, 2025: humans gathered here daily to say nothing, loudly, to everyone they knew, forever.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
